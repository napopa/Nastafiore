# Nastafiore

Nastafiore is an Android and web music player for Navidrome and Subsonic, with MusicBrainz catalog browsing, ListenBrainz statistics and optional Lidarr integration. It is an independent fork of [Castafiore](https://github.com/sawyerf/Castafiore), originally created by sawyerf and its contributors.

Nastafiore includes offline music, favorites, playlists, radio, lyrics and translations.

## Connect

Connect to your Navidrome or Subsonic server in Settings.

To add Lidarr, open Settings → Catalog integrations and enter your Lidarr URL and API key. Select **Check connection and load settings**, choose your root folder and profiles, then select **Save integrations**.

[Integration setup and local build instructions](docs/catalog.md)
